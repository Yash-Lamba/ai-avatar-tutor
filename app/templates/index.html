2. Dispatch Video Generation to HeyGen (cURL)

curl -X POST "http://127.0.0.1:8000/api/v1/generate-video" \ -H "Content-Type: application/json" \ -d '{"avatar_id": "Angela-in-business-suit", "lecture_plan": { ... }}'

3. Submit Adaptive Answer & Feedback (Python)

import requests response = requests.post("http://127.0.0.1:8000/api/v1/adaptive-feedback", json={ "question": "If force is kept constant while mass is doubled, what happens to acceleration?", "student_response": "It halves", "correct_answer": "It halves", "concept_context": "Newton's Second Law" }) print(response.json())
